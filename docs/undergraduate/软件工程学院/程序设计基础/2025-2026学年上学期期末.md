### 三、程序分析题（20 分，每题 5 分）

1. 下面程序的输出结果是：（ ）。

    ```c
    void main() {
        int a=0, b=0;
        while(a < 100) {++a;b+=a;}
        printf("%d, ", b);
        a=0;
        while(a < 100) {
            int b;
            ++a;
            b-=a;
        }
        printf("%d", b);
    }
    ```

    ***

2. 下面程序的输出结果是：（ ）。

    ```c
    #include<stdio.h>
    typedef char string[2000];
    void main() {
        char *p[]={"hello, ", "world", "abc", "123", "!!!"};

        strcpy(s1, p[0]++);
    ```

### 四、编程题（本题满分 40 分，每小题 10 分）

注意程序中适当的注释和良好的编程风格都是得分点。

1. （10 分）编写程序，找出 $1\sim100$ 之间所有“逢 7 过”的数字并输出。所谓“逢 7 过”是指：该数字或者是 7 的倍数，或者个位数是 7，或者十位数是 7。要求：一行输出 5 个数字，数字之间用空格隔开。实现的程序输出如下图所示：

    ```text
    7 14 17 21 27
    28 35 37 42 47
    ...（后续省略）
    ```

    ***

2. （10 分）编写一个函数 `int IsPalindrome(const char *str)`，用于判断传入的字符串是否是“回文串”。如果是回文串，返回 1；否则返回 0。回文串是指正读和反读都一样的字符串，例如 “level”、“12321”、“aba” 都是回文串。输入的字符串长度范围为 $[1,50]$。

    ***

3. （10 分）编写一个递归函数 `void ToBinary(int n)`，实现十进制转二进制输出，功能是将传入的正整数 $n$ 转换为二进制形式并输出（前缀 0 不需要输出）。要求：**必须使用递归思想实现**；函数只需要打印结果，不需要换行。

    示例：如果 $n=7$，则程序输出 111。

    ***
